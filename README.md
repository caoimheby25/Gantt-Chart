Gantt Chart
A collaborative software engineering project with Jack Temple

A simple project management tool that allows users to plan, organize, and track tasks using a Gantt chart. The project demonstrates how tasks, timelines, deadlines, and project progress can be visually represented in an organized format.

Features
- Create and organize project tasks
- Display task timelines and durations
- Visualize project progress
- Track deadlines and scheduled activities
- Simple and efficient implementation
- Beginner-friendly code for learning project management concepts

Purpose
This project was created to practice working with task scheduling, timelines, data organization, and visual project planning while building a practical Gantt chart application.

Tech Stack
- Programming Language: C
- Git & GitHub
